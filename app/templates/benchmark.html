Method

  • {{ run_count }} timed runs per method, interleaved so network variation is shared evenly.
  • Three untimed warm-up runs per method are discarded first.
  • PostgreSQL is hosted on Neon and MongoDB is hosted remotely, so both are reached over the network. Redis runs locally in Docker.
  • The application opens a new PostgreSQL connection on every request, which is why the first column is so much slower than the third.
  • The third column still crosses the network for both queries, so the gap between it and Redis is the cost of two remote round trips against one local in-memory read — not a claim that the Redis engine is faster than PostgreSQL at equal distance.
  • The benchmark reads the cache directly and never records a view, so it does not affect the trending rankings.
